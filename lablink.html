TIME TO FIRST SANDBOX ORDER

From signup to your first sandbox order

Six steps against the sandbox base URL, https://lablink.caregap.io/api/sandbox/v1. Sandbox data is synthetic: nothing reaches a real lab or patient, and nothing is billed. Every request below is from the OpenAPI spec; the API docs have every field.

  1. STEP 1

    Get a sandbox key

    Create your LabLink account (no payment needed for sandbox), then open API keys & webhooks in the console and create a sandbox key. It is shown once. Send it on every request as Authorization: Bearer <key>. A sandbox key works only on the sandbox base URL, and a production key only on production. The examples read it from $LABLINK_API_KEY.

  2. STEP 2

    Create a test patient

    Only firstName, lastName and dateOfBirth are required. Send your own externalId: retrying a create with it returns 409 conflict and the existing id instead of a duplicate.

    POST /patients
    curl -X POST "https://lablink.caregap.io/api/sandbox/v1/patients" \
  -H "Authorization: Bearer $LABLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"firstName":"Ada","lastName":"Sample","dateOfBirth":"1985-04-12","sexAtBirth":"Female","gender":"Female","externalId":"your-app-4821"}'

    Returns 201 with the patient, including its id ("160742" in these examples).

  3. STEP 3

    Find a test and read its questions

    The catalog runs to thousands of tests, so filter by part of the name (search) or the Quest order code (code). Then fetch each test you will order: if its questions are not empty, every one needs an answer in the order.

    GET /tests
    curl "https://lablink.caregap.io/api/sandbox/v1/tests?search=cbc" \
  -H "Authorization: Bearer $LABLINK_API_KEY"
    GET /tests/{id}
    curl "https://lablink.caregap.io/api/sandbox/v1/tests/92314142" \
  -H "Authorization: Bearer $LABLINK_API_KEY"

    A test's id and its Quest code both work in an order. In these examples, CBC is id 92314142, code 6399.

  4. STEP 4

    Place the order

    One request: patient, address, tests, ordering provider, ICD-10-CM diagnosis codes, bill type and any answers. Every sandbox organization has a test provider, Test Physician, NPI 1336176510. The address is required the first time you order for a patient. Patients in Rhode Island are not served.

    POST /orders · cURL
    curl -X POST "https://lablink.caregap.io/api/sandbox/v1/orders" \
  -H "Authorization: Bearer $LABLINK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"patientId":"160742","patientAddress":{"line1":"100 Example Ave","city":"Austin","state":"TX","postalCode":"78701"},"tests":[{"code":"6399"}],"providerNpi":"1336176510","diagnosisCodes":["E11.9"],"billing":"client"}'
    POST /orders · JavaScript
    const res = await fetch('https://lablink.caregap.io/api/sandbox/v1/orders', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LABLINK_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    patientId: '160742',
    patientAddress: { line1: '100 Example Ave', city: 'Austin', state: 'TX', postalCode: '78701' },
    tests: [{ code: '6399' }],
    providerNpi: '1336176510',
    diagnosisCodes: ['E11.9'],
    billing: 'client'
  })
});
const order = await res.json();
if (!res.ok) {
  // Every error has the same shape. Quote requestId to support.
  throw new Error(`${order.error.type}: ${order.error.message} (${order.error.requestId})`);
}
if (order.actionRequired) console.log(order.actionRequired.message);

    Returns 201 with the order: status: "created", its steps, and actionRequired: null when LabLink could finish the questionnaire and provider authorization itself.

  5. STEP 5

    Follow the order

    status moves from created to awaiting_collection (Quest has the requisition) to results_final, or cancelled. If actionRequired is set, its message names the call that finishes it: POST /orders/{id}/answers, /provider or /billing.

    GET /orders/{id}
    curl "https://lablink.caregap.io/api/sandbox/v1/orders/92322840" \
  -H "Authorization: Bearer $LABLINK_API_KEY"

  6. STEP 6

    Handle webhooks

    Register an endpoint on the console's API keys & webhooks page, separately for sandbox and production, each with its own signing secret. LabLink sends order.awaiting_collection when Quest has the requisition (then download the PDF the patient brings to the draw with GET /orders/{id}/requisition) and order.results_final with Quest's results. Verify LabLink-Signature against the raw body, answer 2xx within 10 seconds, and dedupe on the event id: deliveries are at least once. You can send a test event from the console. More on results.

    Verify LabLink-Signature · Node.js
    import crypto from 'node:crypto'

// LabLink-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256 of `${t}.${rawBody}`>
// Use the raw request body: re-serialized JSON will not match.
export function verifyLabLinkSignature(rawBody, header, secret, toleranceSeconds = 300) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=')))
  const t = Number(parts.t)
  if (!t || !parts.v1) return false
  if (Math.abs(Date.now() / 1000 - t) > toleranceSeconds) return false
  const expected = crypto.createHmac('sha256', secret).update(`${t}.${rawBody}`).digest('hex')
  return expected.length === parts.v1.length &&
    crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(parts.v1))
}

Sandbox to production checklist

None of this blocks building in sandbox. All of it is needed before your first real order.

  • ! Production ordering through the API is not open yet. On production, creating an order returns not_available until production billing is in place.
  • ✓ A licensed ordering provider with an active NPI, verified with their state license
  • ✓ The CareGap Platform Agreement and BAA, e-signed
  • ✓ A payment method on file, with onboarding paid
  • ✓ Your Quest subaccount issued, or your existing Quest account connected, through to a client number
  • ✓ A production key, and a production webhook endpoint with its own signing secret
  • ✓ For insurance orders, your flow collects the patient's coverage and ICD-10-CM codes

Stuck in sandbox?

  • Every error has the same shape: branch on error.type, read message for what to change, and param for the field at fault.
  • 401 unauthorized usually means a sandbox key on the production URL, or the reverse.
  • If the order has actionRequired, make the call its message names.
  • Send the same call from the playground in the LabLink console and compare it with your request.

Still stuck? Email support@caregap.io with the requestId from the error (also in the LabLink-Request-Id header). Never include patient data or API keys.

Who We Work With

Questions people actually ask

How much does LabLink cost?

A $1,500 one-time subaccount onboarding fee, an order platform fee of $5.00, $3.00 or $2.00 per order graduated by monthly volume, and $1.00 per patient record per year. Laboratory testing is billed separately by Quest according to the bill type on each order. Pricing is indicative; final terms are set in the CareGap Platform Agreement.

Do I need my own Quest account?

No. If you are new to Quest, LabLink onboarding sets up a Quest subaccount for your organization and tracks it to a client number. If you already have a Quest account, you can bring it. Either way you need a licensed ordering provider with an active NPI, and the $1,500 one-time onboarding fee applies. More on ordering without your own Quest account.

Can I still order on CareGap's Quest account with no setup fee?

No. Earlier CareGap pages at caregap.io/quest and caregap.io/lab-ordering described ordering on CareGap's own Quest account with no setup fee, and a separate plan for your own account. Those offers have been retired and are not available. LabLink is CareGap's current lab ordering offer.

How does billing work?

There are two separate streams. CareGap charges its platform fees (onboarding, per-order and per-patient record fees) to the payment method on file. Quest bills laboratory testing according to each order's bill type: your subaccount for Client Bill, the patient for Patient Cash, or the patient's health plan for Patient Insurance.

I already have a Quest account. Can I use LabLink?

Yes. LabLink works with existing Quest customers and with organizations that are new to Quest. Pricing is the same either way, including the $1,500 one-time onboarding fee. Tell us which you are at signup and we take it from there.

Can I bill insurance?

Yes. You can order as Client Bill, Patient Cash or Patient Insurance. Insurance orders are billed by Quest to the patient's health plan and require insurance details and ICD-10 codes. You can use different bill types for different orders.

What does a test actually cost?

That depends on the bill type. Client Bill orders are billed by Quest to your subaccount at Quest's program rates. Patient Cash orders are billed by Quest to the patient at its standard patient pricing. Insurance orders are billed to the plan. CareGap does not sell, bill or collect for laboratory testing.

Do platform fees apply to insurance and patient cash orders?

Yes. The onboarding, order platform and patient record fees are technology fees and apply to every order, regardless of bill type.

How does the graduated order fee work?

Each order is charged at the rate for its position in the month: orders 1 to 100 at $5.00, 101 to 500 at $3.00, and 501 and above at $2.00. Earlier orders are not repriced, and the count resets on the first of each month. 300 orders in a month is (100 × $5.00) + (200 × $3.00) = $1,100.

Do I really need an NPI?

Yes. Every order requires a licensed ordering provider with an active NPI, whoever pays for the test. If you have your own clinician or a telehealth partner, you are covered. If you do not have one yet, tell us below and we will point you at options.

Can I charge my patients more than I pay?

On Client Bill orders you set your own retail price inside your app. Roughly half the states regulate re-billing lab work through direct-bill, anti-markup or disclosure statutes, so have counsel review before you publish pricing.

Do you support at-home collection?

Yes, as an add-on through our mobile phlebotomy partner, in addition to Quest patient service centers.

We do not have a dev team. Can you build the app?

Yes. The CareGap build team can design, build and maintain your branded app or portal on top of LabLink. Book a call and we will scope it.

Can I place production orders today?

Not yet. Ordering through the API is open in sandbox today. On production, creating an order returns not_available until production billing is in place. You can build and test the whole integration in sandbox, including webhooks, and talk to us about production timing.

How fast can I be in sandbox?

Right away. Your sandbox opens when you create your account, before any payment, and does not wait on Quest paperwork. You can be calling the API and building while your subaccount is being set up.
